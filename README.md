This was a game engine I made for a University assignment.

Most of the engine basics work, aside from a memory leak or two here or there. I am working on an improved version in my spare time, which I will eventually post about.

Features (from what I remember):
- Graphics rendering of 2D sprites (and memory managed),
- Basic sound loading / playing,
- Camera system (moving around the map, zoom, scroll etc),
- basic gameplay (placing of structures and units, etc).
